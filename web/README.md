## 与后端的约定

- 所有接口前缀 `/api/v1`，开发时通过 dev server 的 proxy 转发到 `http://127.0.0.1:8000`
- 统一响应 `{"code": 0, "message": "成功", "data": {...}}`，`data` 为空时不输出该字段
- 鉴权 `Authorization: Bearer <access_token>`，401 时用 refresh token 换新的
- 时间字段形如 `2026-11-09T21:39:04Z`，**这个 `Z` 不是 UTC**，
  直接 `new Date()` 解析会多 8 小时，需要先去掉 `Z`
- 分页字段不统一：文章列表 `page_size`，后台用户列表 `pageSize` —— 契约如此，照抄
