## 环境备忘（本机）

- Python 3.13.0，`.venv` 在项目根
- MySQL 8.0.44 在 `F:\mysql8.0.44\mysql-8.0.44\bin`（需手动加 PATH），root 有密码
- 无 Docker
- pip 用清华源；`sqlalchemy[asyncio]` 必须带 extras，否则缺 greenlet 直接 import 失败
