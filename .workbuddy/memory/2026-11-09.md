- 新增关键坑：
  - 服务器已有 `blog_mysql_data`（189M，2026-10-27 前老库），新卷必须叫 `blog_v2_mysql_data`，否则 Alembic 在旧表上硬改
  - `TEXT` 64KB 静默截断 → 文章正文用 `MEDIUMTEXT`（`Text().with_variant(MEDIUMTEXT, "mysql")`）
  - `TINYINT(1)` 会被驱动映射成 bool → status 显式 `SmallInteger`
  - `pool_recycle=3600` 必写（MySQL wait_timeout 8h）
  - MySQL DDL 隐式提交，migration 失败不能回滚
  - 不要加 `--lower-case-table-names`（只能在初始化时设，且 Linux 默认 0 正合适）
  - 唯一索引大小写不敏感（`Admin` = `admin`），是行为变化不是 bug
- 新库精简：articles 删 4 个 vector_* 列，ai_model_configs 删 `dimension`/`name` 列，前端 AdminView 文章表格要同步删 4 列
